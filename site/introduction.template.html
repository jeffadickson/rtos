A web page is content + transport
Start in ROM. Connect your transport.
Ethernet
A bounded HTTP session can sit behind an existing TCP/IP stack. The current polling Ethernet adapter is not a TCP/IP implementation. MAC, PHY and stack ownership remain board integration work.
Serial
Use the same HTTP bytes over a UART stream. A browser needs a host gateway or Web Serial; a serial port is not an IP network. The viewer below requires a user-selected, configured device.
QSPI flash
A useful optional asset and firmware store. Begin with read-only assets, explicit geometry and bounds. Erase/program need deadlines, staging and recovery. QSPI does not provide Ethernet or define an input protocol.


Serial HTTP viewer
Experimental host viewer for a board application implementing the documented HTTP-over-UART contract. Desktop Chromium Web Serial requires HTTPS or localhost and an explicit device permission. No device is opened automatically.

What grows beyond a nano kernel?
RTEMS provides mature managers for synchronization, message queues, events, timers, periodic execution and fixed partitions, together with broad BSP, filesystem and POSIX facilities. NexRT adopts bounded pieces incrementally. It does not claim RTEMS or Xenix compatibility.
Implemented optional services include typed queues, events, counting semaphores, priority-inheriting mutexes, single-hart atomic words and bounded queued printf. Still requiring implementation or qualification: external peripheral IRQ dispatch, additional IPC breadth, software timers, VFS/filesystems, networking, driver BSPs, SMP, POSIX subsets, protected processes, fault containment and certification evidence.
